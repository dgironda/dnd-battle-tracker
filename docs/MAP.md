## functions/api/patreon/

- `exchange.ts`: POST /api/patreon/exchange { code } → { isSupporter, personId } The redirect lands the browser back here with `?code=…`.
- `health.ts`: GET /api/patreon/health → which pieces of the Patreon gate are configured.
- `session.ts`: GET /api/patreon/session → { isSupporter, personId } DELETE /api/patreon/session → signs out This is what makes the gate real.

## functions/api/room/[code]/

- `[role].ts`: GET /api/room/:code/host the DM's tracker (WebSocket) GET /api/room/:code/player a player's page (WebSocket) The door to a shared battle.
